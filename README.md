DEFAKE-Spider 

AI-Generated Image and Video Detection System

DEFAKE-Spider is a machine learning-based project designed to identify whether digital images and videos are real or AI-generated.

DEFAKE aims to address this problem by leveraging Machine Learning, Deep Learning and Computer Vision techniques to analyze images and classify them based on their authenticity.

The project will initially focus on image classification and will gradually expand towards deepfake face detection and video authenticity analysis.
